## Beginner Roadmap

If you are new to the repo, use this order:

1. Learn the C++ basics needed for interviews with [STL Notes](./STL_Notes.md).
2. Build data structure fundamentals with [Stack](./Stack_Notes.md), [Queue](./Queue_Notes.md), [Linked List](./Linked_List_Notes.md), [Trees](./Tree_Notes.md), and [Graphs](./Graph_Notes.md).
3. Study common patterns from [Algorithms Notes](./Algorithms_Notes.md).
4. Use the subject guides for fundamentals: [Operating Systems](./OS/README.md), [Computer Networks](./CN/README.md), and [DBMS](./DBMS/README.md).
5. For each topic, read once, solve the practice exercises, then explain the core ideas aloud without notes.

## Usage

Use these notes as a revision and practice companion. The best workflow is:

1. Read the topic overview.
2. Recreate diagrams or examples by hand.
3. Solve the practice questions.
4. Add missing examples or corrections through a pull request.
